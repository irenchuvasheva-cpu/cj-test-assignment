# Исправление рассылки вакансий

Редакторы заметили: после неудачной отправки часть вакансий пропадает из следующих рассылок.

В архиве — локальный код и тестовые данные. Найдите причину, добавьте тест, который воспроизводит проблему, и исправьте её. Сохраните остальное поведение.

Пришлите код и короткое объяснение: в чём причина, что изменили и как проверили. Можно пользоваться ИИ.

Ориентир — 60–90 минут. Telegram и доступ к проду не нужны.

```bash
python digest.py jobs_sample.json
python digest.py jobs_sample.json --free
python -m unittest -v
```
