## Задание 1. Парсер вакансий Booking

Мы узнали, что в Booking работает много наших ребят, и хотим автоматически собирать вакансии компании, чтобы наши редакторы узнавали обо всех новых позициях.

Напишите парсер страницы [Booking Careers](https://jobs.booking.com/booking/jobs).
Код должен запускаться в Google Colab. Добавьте команды установки необходимых зависимостей.

### Результат

1. Список `rows` со всеми открытыми вакансиями компании на момент запуска, с учётом пагинации или подгрузки. Исключите дубликаты по ссылке. Формат каждой записи:

```python
rows.append({
    'company': 'Booking.com',
    'position': position,
    'link': link,
    'location': location,
})
```

`link` — абсолютная ссылка на вакансию. Если локация не указана, используйте пустую строку.

2. Лог результата:

```python
print(f"Booking: добавлено вакансий {added} (из {len(all_jobs)} проверенных)")
```

`all_jobs` — собранные записи до исключения дубликатов, `added` — количество записей, добавленных в `rows`.

3. Обработка ошибок с понятным сообщением:

```python
except Exception as e:
    print(f'✗ Error in Booking: {e}')
```

Если сбор прервался, явно укажите, что результат неполный.
Сравнение с предыдущими запусками и отправка уведомлений в это задание не входят.

## Задание 2. Исправление рассылки вакансий

Редакторы заметили: после неудачной отправки часть вакансий пропадает из следующих рассылок.

В папке [task-2-digest](task-2-digest/) — локальный код и тестовые данные:

- [digest.py](task-2-digest/digest.py) — логика рассылки;
- [jobs_sample.json](task-2-digest/jobs_sample.json) — вымышленные вакансии;
- [test_digest.py](task-2-digest/test_digest.py) — существующие тесты;
- [README.md](task-2-digest/README.md) — описание второй задачи.

Найдите причину, добавьте тест, который воспроизводит проблему, и исправьте её. Новый тест должен падать до исправления и проходить после него. Существующие тесты не удаляйте и не ослабляйте. Сохраните остальное поведение.

Нужен Python 3.11+. Telegram, база данных и доступ к проду не нужны.
Запуск из папки `task-2-digest`:

```bash
python digest.py jobs_sample.json
python digest.py jobs_sample.json --free
python -m unittest -v
```
